# ITM College Website

A modern, responsive educational website template for colleges, universities, and training institutes. 
Built to showcase courses, admissions, events, and college resources in a clean and professional layout.

## 🎯 Project Purpose

The purpose of ITM College Website is to provide an all-in-one digital platform for educational institutions to:
1. **Showcase Academic Programs** - Display diverse courses with booking/enrollment options
2. **Improve Student Engagement** - Highlight events, news, gallery, and facilities
3. **Simplify Admissions** - Provide direct access to admission info, registration, and login
4. **Build Institutional Credibility** - Present the college brand with a professional hero section and structured content

This template is ideal for colleges offering programs in Hotel & Tourism Management, Engineering, Marketing, and other fields.

## ✨ Key Features

### **1. Navigation & Branding**
- Top navbar with: Home, About Us, Admission, All Courses, Login, Contact Us
- College logo and search bar for courses
- Responsive header for desktop and mobile

### **2. Hero Section**
- Full-width banner with college building background
- Headline: "WELCOME TO ITM COLLEGE"
- CTA Buttons: `ALL COURSE` and `READ MORE`
- Tagline focused on international careers in Hotel & Tourism Management

### **3. Discover Section**
Quick access cards for:
- **Academics**
- **Admission**
- **Facilities**
- **Courses**
- **Seminar 2024**
- **Facilities**

### **4. Course Catalog**
Displays multiple courses with:
- Course image, name, and category
- Start date and available seats
- `BOOK NOW` button for enrollment
- Courses included: Chemistry, Geology, French, Data Analytics, Economics, Marine Engineering, Digital Marketing, Architecture

### **5. Events & Updates**
- **Upcoming Events**: Dated event list like "Latino College Expo", "Training at Team Fabio"
- **Job Vacancies**: Latest job posts from the institution
- **Register & Login**: Quick access panel for students
